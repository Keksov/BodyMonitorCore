# BodyMonitorCore

Target location for the extracted body-monitor core product.

Current ownership in this product:

- `products/BodyMonitorCore/cli/BodyMonitor`
- product-local Pascal vendor bindings under `products/BodyMonitorCore/cli/BodyMonitor/vendor`
- product-local Pascal helpers and stdio protocol under `products/BodyMonitorCore/cli/BodyMonitor/common`
- `products/BodyMonitorCore/server`
- body-monitor UI modules from `products/BodyMonitorCore/ui`

The legacy `pas/MindReader` tree has been moved into the product-local CLI area and renamed to `BodyMonitor`.
